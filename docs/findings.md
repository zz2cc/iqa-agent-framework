## F-001：VLM 对 JPEG 压缩与变暗失真存在系统性盲区

- **日期**：2026-07-23
- **证据**：失真阶梯 200 源 × 4 族 × 3 档，32B 端点准确率：模糊 0.99 / 噪点 0.97，但 **JPEG 0.77 / 变暗 0.82**；相邻档单调性 JPEG 0.36 / dark 0.41（S-TECH），远低于模糊 0.73。
- **解读**：暗部感知弱是 VLM 公认短板（Tool-IQA 专门为暗部设计 Gamma Corrector）。JPEG q=70→40 在已压缩网络图上本就难以察觉。
- **验收用法**：VLM 先验分布的结构性特征——"哪些失真模型天生就不敏感"——说明 prompt 工程和各路评分需要互补。

## F-002：同源多专家的融合权重 ≈ 等权（阴性结果）

- **日期**：2026-07-23
- **证据**：阶梯上坐标下降拟合五专家融合权重，4 族交叉验证：拟合 vs 等权仅 +0.005~0.009；全体拟合 0.822 vs 等权 0.815（+0.007）。
- **解读**：五专家同源（同一 VLM），分数相关性 0.7-0.9。"解释的多样性 ≠ 预测的多样性"。这个阴性结果直接说明需要外部信号（后来的 BT 锦标赛）才能打破同源天花板。
- **验收用法**：R1→R2 稀释的根因（0.633→0.606）；为什么需要 BT 锦标赛来训练门控。

## F-011：自洽性提升 ≠ 人类对齐提升（锚相关性定律的起源）

- **日期**：2026-07-25
- **证据**：CKE 9 条规则改善内部指标（阶梯 mono 0.455→0.474，B-C 分歧 0.402→0.33），外部 SRCC 仅 +0.001（R2.5 0.619→R3 0.621）。
- **解读**：CKE 两个驱动信号（B-C 自洽性 + 合成失真单调性）优化的是模型内部一致性，而非与人群分的对齐。**一整套 ¥69 的自进化流程换来近乎零的外部收益**——项目的核心负结果，催生了贯穿全文的锚相关性定律。
- **验收用法**：核心叙事——"自洽≠对齐"是 CKE 失败提炼出的方法论基石。

## F-013：BT 锦标赛的边密度定律

- **日期**：2026-07-25
- **证据**（仿真 300 节点）：稀疏链图（4 边/节点）下 BT 恢复 SRCC 0.543；密度增至 ~7 边/节点时首次反超旧分排序（0.955 vs 0.901）；瓶颈是图拓扑（每节点边数），不是拟合算法或判噪。
- **解读**：两两比较的信息全部来自比较边。"每图几对"的设计在数学上无法超过旧分——随机长程边才是骨架，相邻对只能做局部微调。
- **验收用法**：BT 锦标赛配对设计的理论依据——为什么需要 32,000 场对决。

## F-016：SPAQ 绝对评分塌方 vs 两两比较（协议瓶颈，非模型瓶颈）

- **日期**：2026-07-25
- **证据**：SPAQ 失真阶梯上，6 族绝对打分门控全部 FAIL（模糊仅 0.65），同一批图的两两比较达到 0.98/0.88——**相差一个量级**。
- **解读**：SPAQ 绝对打分全族失效不是模型能力问题，是 0-10 量程上评分噪声太大。绕开量程的两两比较立刻恢复分辨力。
- **验收用法**：为什么 R6 用 BT 锦标赛——协议设计先于模型能力。

## F-017：全量 BT 锦标赛双域 GO + 锚相关性定律首次获证

- **日期**：2026-07-25
- **证据**：KonIQ（补密后 11,707 场）G2 +0.116、G3 0.860 PASS；SPAQ（补密后 4,045 场）G2 +0.048、G3 0.889 PASS。边密度定律在真数据上二次验证。
- **解读**：同一融合代码，监督信号从合成失真换为 BT 排行榜后，收益从一轮的 +0.007 跳到 +0.062——**同一机制、不同信号、收益差近一个量级**。锚相关性定律在 Router 层面首次获得正向证据。
- **验收用法**：F-002→F-017 之间的对照是"为什么 BT 有效"的最核心证据链。

## F-021：偏置方向翻转的真凶是内容先验，不是量程

- **日期**：2026-07-26
- **证据**：200 张同图分别用 1-5 和 0-10 bare prompt 打分，相对位置 Δ=3.2pp（方向与猜测相反且量小）→ 量程假说证伪。同一 prompt 下 KonIQ 图 0.630 vs SPAQ 图 0.441——**模型先验的内容依赖零点摆幅 19pp，而标注人群仅 6pp**。
- **解读**：对野生网图偏宽容（+5.8pp）、对手机照片偏苛刻（−3.9pp），与量程无关。偏置不是"刻度没对齐"，是"模型对不同内容自带不同偏见"。
- **验收用法**：MAE 偏置的根本原因——在 §4.5 约束下原则性不可达，但病根已精确定位。

## F-022：CLIP-IQA 外援门控 FAIL——异质信号须携带独立信息

- **日期**：2026-07-26
- **证据**：CLIP-IQA（ViT-B-32，零样本）对 BT 排行榜 SRCC KonIQ 0.599 / SPAQ 0.558，弱于 VLM 融合（0.817 / 0.954），50/50 混合反而稀释。
- **解读**："多样性必须携带独立信息，仅仅换个模型家族不算"（F-002 的广义化）。门控拒收了 CLIP——不因为不好，因为结合后反降。
- **验收用法**：门控纪律的案例——"敢拒"比"敢加"更能证明系统可信。

## F-024：提示词约束的保序-校零分离

- **日期**：2026-07-25
- **证据**（消融梯度，R1-anchor v3 为考后诊断臂）：
  | 臂 | KonIQ SRCC | MAE | SPAQ SRCC | MAE |
  |---|---|---|---|---|
  | R1-bare (纯裸问) | 0.660 | 0.454 | 0.884 | 0.819 |
  | R1-anchor v3 (+人设/锚点/程序) | 0.625 | 0.645 | 0.865 | 1.062 |
  | R1-rich (完整专家) | 0.633 | 0.688 | 0.867 | 1.042 |
- **结论**：排序一致性（SRCC）与绝对校准（MAE）是两种可分离的能力。锚点评分带注入排序知识（维持 SRCC），同时框死输出分布零点（恶化 MAE）。约 65% 附加 MAE 偏置来自锚点层。
- **解读**：锚点损益随数据集变号（SPAQ 上同一锚点反将偏置往 MOS 方向拉）。盲写先验不可能同时命中两个数据集——这正是指标背后的"零点校准不可达"原理。
- **验收用法**：发现章节的核心素材——"给模型提示越详细，分数偏差反而越大"的反直觉实证。
